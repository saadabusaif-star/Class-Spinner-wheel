PRIVACY BY DESIGN

Names are not public data.

GitHub Pages is static hosting. This version encrypts roster data with Web Crypto before saving it in this browser's local storage. It does not provide server accounts or shared storage.

For real school deployment, host the full app on a platform that supports Node.js, database, authentication, and server-side encryption.
